# Preparing a citable specification release

1. Review the Core requirements and resolve release-blocking items in `OPEN_ISSUES.md`.
2. Confirm authorship, repository visibility and documentation/code licenses.
3. Verify examples against the declared schemas and run semantic/source-fidelity review where applicable.
4. Freeze the specification, schemas and examples together. Identify their version and exact commit.
5. Update citation metadata with the approved author list, release date and repository URL.
6. Prepare the archive deposit with the specification and supporting files. Confirm the public content and metadata before publication.
7. Publish the approved archived version and record the DOI returned by the archive. A reserved DOI alone does not establish a published release.
8. Add the version-specific DOI to the repository citation metadata. Preserve the released files and record subsequent changes in a new version.

The public working repository is https://github.com/TaylorResearchLab/PAR. A working draft commit, a tagged GitHub release and a published Zenodo deposit are separate steps. This draft does not carry an assigned archival DOI.
